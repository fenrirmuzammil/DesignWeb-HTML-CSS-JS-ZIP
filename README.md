# DesignWeb Landing Page

![DesignWeb Preview](reference-design.png)

A modern, responsive landing page recreated directly from design specifications using pure HTML, CSS, and JavaScript.

---

## 📁 Repository Structure

* `index.html` — Main HTML document structure
* `style.css` — Custom styles, animations, and responsive layout
* `script.js` — Interactive UI, scroll animations, and counter logic
* `reference-design.png` — Visual reference blueprint

---

## 🚀 Quick Start

Simply open `index.html` directly in your browser or serve it using Live Server / local HTTP server.

---

## ✨ Features & Functionality

* **Responsive Navigation:** Interactive desktop navigation & mobile drawer menu
* **Scroll Highlighting:** Active section indicators on navigation links during scroll
* **Reveal Animations:** Subtle reveal-on-scroll effects for elements
* **Animated Metrics:** Interactive growth progress bars and statistics counters
* **Mouse Parallax:** Gentle background parallax movement on cursor hover
* **Device Mockup:** Clean, responsive laptop/dashboard component
* **UI Components:** Styled service cards, feature grids, and high-converting CTA sections
* **Accessibility:** Respects `prefers-reduced-motion` browser settings

---

## 🎨 Design System

The layout recreates the white, purple, and blue modern tech design using editable HTML/CSS structure rather than static flattened assets.

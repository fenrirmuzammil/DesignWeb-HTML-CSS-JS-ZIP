NovaWeb Landing Page
=====================

Files:
- index.html
- style.css
- script.js
- reference-design.png (visual reference)

Open index.html directly in a browser.

The page is responsive and includes:
- responsive navigation + mobile menu
- scroll navigation highlighting
- reveal-on-scroll animations
- animated growth bars
- animated statistics counters
- subtle mouse parallax
- responsive laptop/dashboard mockup
- service cards and CTA
- reduced-motion friendly behavior

The CSS recreates the supplied white/purple/blue design as editable HTML/CSS rather than flattening the whole page into one image.
